# Postify - Django Social Media App

**CodeAlpha Internship Project - May 2026 Batch**

### Features:
- User Registration & Login System
- Create, View, Delete Posts
- News Feed with all user posts
- Like/Unlike functionality
- Profile Page
- Friends Page

### Tech Stack:
- Backend: Django 5.0.4, Python
- Frontend: HTML, CSS, Bootstrap 5
- Database: SQLite3

### How to Run Locally:
1. Clone the repo: `git clone https://github.com/ananthi-1003/postify.git`
2. Install requirements: `pip install -r requirements.txt`
3. Run migrations: `python manage.py migrate`
4. Start server: `python manage.py runserver`
